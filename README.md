# App4U

App4U 是一个免费应用推荐项目，专注于发掘和分享个人开发者及小团队打造的优质作品。

因我本人也是从独立开发做起，深知流量获取之难，也常见很多独立开发者朋友苦于运营乏力，遂发起此项目，希望让更多用心、有创意的应用被看见，也希望给大家介绍一些好的作品。

应用介绍会发布于【钱迹记账】公众号，目前有 6 万+ 粉丝，推荐标准如下：

- 不限于移动端 App，Web/PC 应用皆可
- 应用商店评分≥4.5（如果是新上线应用可酌情降低要求，无公开评分的产品以实际体验为准）
- 无 **抄袭** 争议
- 无欺诈行为、严重 Bug 等问题

暂定每两周推荐一次，而且每款产品我会亲自体验一段时间。

产品是否收费、是否提供激活码不影响评选结果，只看创意或者使用体验，如果不符合预期，会拒绝。
